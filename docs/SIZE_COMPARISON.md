# Track C ISO Size Evaluation

## Custom Linux ISO
Optimized Track C ISO: 1,397,649,408 bytes
Approximately 1.398 GB.

## Official Ubuntu Reference
Ubuntu 24.04.5 Server installer ISO: approximately 3.8 GB.
Ubuntu 24.04.5.1 Desktop installer ISO: approximately 5.8 GB.

Official source:
https://releases.ubuntu.com/24.04.5/

## Comparison
Track C is approximately 63% smaller than the
official Ubuntu 24.04.5 Server installer ISO,
using the published rounded sizes.

This exceeds a 40% size-reduction target if
the official Server installer is the accepted baseline.

## Important Qualification
The stock Ubuntu installer and custom Track C
live image have different contents and functions.
This is an ISO-size comparison, not proof of
equivalent functionality.

The custom ISO is larger than the project's
own minimal base ISO of 1,182,541,824 bytes.

The assignment's exact baseline requirement
must determine which comparison is valid.
